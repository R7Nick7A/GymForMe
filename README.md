# Тренер — мониторинг тренировочного процесса

Личное веб-приложение (PWA для iPhone) для мониторинга, анализа и прогнозирования тренировок с ИИ-помощником.

## Возможности

- Ввод тренировок: вручную, текстом из заметок или фото/скриншотом (ИИ распознаёт и логически разбирает структуру).
- Мониторинг: дашборд, график объёма нагрузки, частые упражнения, статистика.
- Анализ и прогноз: ИИ анализирует историю и даёт прогноз прогресса.
- ИИ-помощник (чат): видит все данные приложения и отвечает на вопросы.
- Планы: ИИ составляет тренировочные планы на несколько недель.
- iOS-дизайн по Human Interface Guidelines, тёмная тема, PWA (можно «Добавить на главный экран»).

## Стек

- **Бэкенд:** Node.js (24+) + Express + SQLite (без внешней БД).
- **Фронтенд:** React + Vite + Tailwind CSS.
- **ИИ:** Google Gemini (бесплатный тариф) — распознавание фото/текста, помощник, прогнозы.

## Запуск (локально)

```bash
cd backend
npm install
node server.js
```

Приложение будет доступно на `http://localhost:3100`.

> SQLite использует встроенный модуль `node:sqlite`, поэтому нужен Node.js **24+**. В DeepSeek Harness он есть по адресу `C:\Users\Nikolay\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe`.

## Подключение ИИ (Gemini)

1. Открой https://aistudio.google.com/apikey и создай бесплатный ключ.
2. Вставь ключ в приложении: шестерёнка ⚙️ на «Главной» → «Настройки» → поле ключа.
   (Или задай переменную окружения `GEMINI_API_KEY`.)

Ключ хранится только локально (в базе SQLite) и используется только для вызовов Google AI.

## Доступ с iPhone

Запусти сервер на компьютере, затем с iPhone (в той же Wi-Fi сети) открой:

```
http://<IP-компьютера>:3100
```

IP можно узнать командой `ipconfig` (строка IPv4). Для постоянного доступа из интернета потребуется бесплатный хостинг или тунель — это можно настроить позже.

## Сборка фронтенда (после изменений)

```bash
npm run build
```
