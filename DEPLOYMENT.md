# Публикация приложения

## Вариант A — бесплатный хостинг, работает при выключенном ПК (рекомендуется)

Постоянно-бесплатная связка: **Render** (веб-сервис) + **Turso** (база данных, совместима с SQLite).
Оба бесплатны без ограничения по дням. Render «засыпает» после ~15 мин простоя и просыпается при первом запросе (10–30 сек).

### Шаг 1. База данных Turso (бесплатно)
1. Зарегистрируйся на https://turso.tech (можно через GitHub).
2. В консоли создай базу: кнопка **Create Database** → любой регион.
3. Открой базу → вкладка **Connect** / **Settings** и скопируй:
   - **Database URL** — вида `libsql://trainapp-xxxx.turso.io`
   - **Auth Token** — длинная строка.

### Шаг 2. Код на GitHub
1. Зарегистрируйся на https://github.com (если ещё нет).
2. Создай пустой репозиторий, например `trainapp`.
3. Загрузи туда содержимое папки `trainapp` (можно через сайт GitHub «upload files»).

### Шаг 3. Render (бесплатно)
1. Зарегистрируйся на https://render.com (через GitHub).
2. **New → Web Service** → подключи свой репозиторий.
3. Render сам увидит `Dockerfile` → выбери **Docker**.
4. В **Environment** добавь переменные:
   - `TURSO_DATABASE_URL` = URL из Turso
   - `TURSO_AUTH_TOKEN` = токен из Turso
   - `GEMINI_API_KEY` = твой ключ Gemini (можно не указывать — тогда введёшь его в приложении)
5. Нажми **Create Web Service** и дождись сборки (3–5 мин).
6. Получишь адрес вида `https://trainapp-xxxx.onrender.com` — открывай с любого устройства.

> Если репозиторий на GitHub не хочется делать — Render умеет деплой из Docker-образа, но это сложнее. Самый простой путь — через GitHub.

## Вариант B — Docker на компьютере (работает, пока ПК включён)

```
cd trainapp
docker compose up -d
```
Приложение на `http://localhost:3100`. Данные хранятся в `backend/data`.

## Вариант C — быстрый туннель (без аккаунтов, временно)

Пока запущен бэкенд на ПК:
```
npx localtunnel --port 3100
```
Даст ссылку вида `https://xxx.loca.lt`. Работает, пока ПК включён и туннель запущен.

## Важно

- Для хостинга используется **Turso** (облачная БД). Локально приложение по-прежнему работает на SQLite — переключение автоматическое по наличию `TURSO_DATABASE_URL`.
- **Фото и загрузки** хранятся на диске сервера. На бесплатном Render диск эфемерный — фото могут пропадать при перезапуске. Тренировки и данные живут в Turso и сохраняются.
- Модели Gemini: приложение само перебирает доступные модели (`gemini-3.5-flash-lite` и др.), если какая-то перегружена.
